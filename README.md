# SPIDERS Applied AI/ML Foundation

A beginner-friendly Python repository covering fundamental programming concepts through simple, practical examples.

## Topics Covered

1. **Variables and Data Types** — Basic data types and collections.
2. **Conditional Statements** — `if`, `elif`, `else`, user input, and exception handling.
3. **Data Structures** — Lists, tuples, sets, and dictionaries.
4. **Loops and Patterns** — `for` loops, `while` loops, number series, and patterns.
5. **Functions** — Function definitions, arguments, return values, prime numbers, and factorials.
6. **File Handling** — Reading, writing, appending, and searching files.
7. **Object-Oriented Programming (OOP)** — Classes, objects, constructors, attributes, and methods.

## Project Files

- `oops.py`

Python 3

## Purpose

This repository provides practical examples to help beginners understand Python fundamentals and build a strong programming foundation as part of the SPIDERS Applied AI/ML Foundation program.
